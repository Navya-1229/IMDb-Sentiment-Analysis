# IMDb Sentiment Analysis

Machine learning project for classifying IMDb movie reviews as **Positive** or **Negative**.

### Dataset

The project uses the IMDb Dataset of 50K Movie Reviews.

- 50,000 IMDb reviews
- 25,000 Positive reviews
- 25,000 Negative reviews

### Approach

The project follows these steps:

- Text preprocessing to clean the reviews
- TF-IDF feature extraction to convert text into numerical features
- Training and comparison of three machine learning models:
  - Logistic Regression
  - Support Vector Machine (SVM)
  - Naive Bayes
- Evaluation based on classification accuracy
- The best-performing model is used for sentiment prediction

### Results

| **Model**           | **Accuracy** |
| ------------------- | ------------ |
| Logistic Regression | **89.36%**   |
| SVM                 | 89.33%       |
| Naive Bayes         | 86.26%       |

**Best Model:** Logistic Regression – **89.36%**
