# IMDb Sentiment Analysis

Machine learning project for classifying IMDb movie reviews as **Positive** or **Negative**.

### Dataset
- 50,000 IMDb reviews
- 25,000 Positive
- 25,000 Negative

### Approach
- Text preprocessing
- TF-IDF feature extraction
- Logistic Regression
- SVM
- Naive Bayes

### Results

| Model | Accuracy |
|---|---:|
| Logistic Regression | **89.36%** |
| SVM | 89.33% |
| Naive Bayes | 86.26% |

**Best Model:** Logistic Regression – **89.36%**
